# Киберзащитник

Учебный vault по информационной безопасности: сети, антивирусы, NGFW и основы ИТ/ИБ. Заметки ведутся в Obsidian, качество проверяется скриптами, публикация — через Quartz.

## Состав

| Раздел | Что внутри |
|---|---|
| Сети_базовый_уровень | Модели OSI/TCP-IP, устройства, VLAN, маршрутизация, протоколы, IPv6, SDN/Overlay |
| Конспекты_занятий/Kaspersky_Endpoint | KES и KSC: файловая защита, контроль устройств и приложений, политики, задачи |
| Конспекты_занятий/NGFW_UserGate | UserGate: зоны, NAT, SSL-инспекция, СОВ, практика |
| Конспекты_занятий/Основы_ИТ_и_ИБ | IT-база: OSI, коммутация и MAC, IP и маршрутизация, базовые протоколы, порты |

## Как читать

1. Откройте MOC нужного домена: MOC_Сети, MOC_Kaspersky, MOC_UserGate_NGFW.
2. В каждом MOC — маршрут обучения (раздел 1) и карта домена (раздел 3).
3. Заметки связаны wiki-ссылками по именам файлов. Начинайте с заметок [база] и хабов [hub].

## Соглашения

- Учебная заметка — шаблон из 7 секций: Зачем нужно → Простыми словами → Технические детали → Пример/команда → Для ИБ → Вопросы для самопроверки → Связи.
- Теги: домен + тема + тип (база / old / hub). Пометка [old] — заметка создана до шаблона и не сверена.
- Целостность проверяет vault_export: аудит секций, манифест битых ссылок, разбиение контента на части.
