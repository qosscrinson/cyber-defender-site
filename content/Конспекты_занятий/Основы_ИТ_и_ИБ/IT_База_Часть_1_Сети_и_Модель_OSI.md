# IT-база. Часть 1: Компьютерные сети и модель OSI

> [!abstract] Кратко
> Базовые определения сети, классификация по масштабу (LAN, MAN, WAN), аппаратные компоненты (хосты, свитчи, роутеры, среды передачи) и базовая сетевая модель OSI (7 уровней).

## 1. Зачем нужно
Прежде чем ловить злоумышленника в логах или настраивать защиту, нужно понимать, как физически и логически устроена сеть. Где заканчивается кабель (L1), где начинается MAC (L2) и IP (L3).

## 2. Простыми словами
Сеть — это компьютеры и провода. LAN — это твой офис. WAN — это интернет. Чтобы два компа договорились, они используют модель OSI — это как матрешка: данные от приложения (браузера) заворачиваются в пакеты, спускаются по уровням до проводов, передаются, а потом на другом конце собираются обратно.

## 3. Технические детали

### 3.1. Классификация сетей
- **LAN (Local Area Network):** Офис, школа, дом. Высокая скорость, принадлежит одной организации.
- **MAN (Metropolitan Area Network):** Город. Объединяет несколько LAN (например, сеть провайдера).
- **WAN (Wide Area Network):** Страна, континент, весь мир. Самый яркий пример — Интернет.

### 3.2. Компоненты сети
- **Хост (Endpoint):** Конечные устройства (ПК, ноутбуки, принтеры, серверы).
- **NIC (Сетевая карта):** Устройство, дающее хосту подключиться к сети (имеет MAC).
- **Среда передачи:** Проводная (медь, оптика) и беспроводная (Wi-Fi, радио, Bluetooth).
- **Сетевое оборудование:** Коммутаторы (свитчи), маршрутизаторы (роутеры), точки доступа.
- **Сервер/Клиент:** Сервер слушает сеть и отвечает на запросы; клиент отправляет запросы (например, браузер).

### 3.3. Модель OSI (7 уровней)
1. **Физический (Physical):** Биты. Кабели, сигналы, разъемы. (Оборудование: хабы, повторители).
2. **Канальный (Data Link):** Кадры (Frame). MAC-адреса. Работа коммутатора. Проверка ошибок (CRC).
3. **Сетевой (Network):** Пакеты (Packet). IP-адреса. Маршрутизация. (Оборудование: роутеры).
4. **Транспортный (Transport):** Сегменты. TCP/UDP. Порты. Доставка данных между процессами.
5. **Сеансовый (Session):** Управление сеансом связи (начало, конец диалога).
6. **Представления (Presentation):** Шифрование, сжатие, кодировки (JPEG, ASCII).
7. **Прикладной (Application):** HTTP, SMTP, FTP. Доступ к сетевым службам.

**Инкапсуляция:** Данные спускаются с 7-го на 1-й уровень (обрастают заголовками), а на приемнике поднимаются с 1-го на 7-й (заголовки отбрасываются).

### 3.4. Типы рассылок
- **Unicast:** Один отправитель — один получатель.
- **Multicast:** Один отправитель — группа получателей (те, кто подписан).
- **Broadcast:** Один отправитель — все устройства в сегменте (широковещательный, MAC `FF-FF-FF-FF-FF-FF`).

## 4. Пример / команда
Посмотреть сетевые интерфейсы (Linux) или IP (Windows):

```bash
# Linux
ip a
# Windows
ipconfig /all
```

## 5. Для ИБ
Злоумышленник может атаковать на любом уровне: подменить кабель (L1), устроить ARP-спуфинг (L2), атаковать IP (L3) или эксплуатировать уязвимость в HTTP (L7). Знание модели OSI помогает локализовать проблему.

| Риск | Защита (Уровень OSI) |
|------|--------|
| Прослушивание трафика в открытом Wi-Fi | L2/L3 — Шифрование (VPN, HTTPS) |
| Подмена MAC-адреса | L2 — Port Security на коммутаторах |
| IP-спуфинг | L3 — ACL, Anti-spoofing |
| Атака на веб-приложение | L7 — WAF, обновления, AppSec |
