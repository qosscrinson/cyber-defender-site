# IT-база. Часть 2: Коммутация, MAC-адреса и VLAN

> [!abstract] Кратко
> Как коммутатор (Switch) передает данные внутри локальной сети. Понимание MAC-адресации, таблицы коммутации, топологий (звезда, шина) и виртуальных сетей (VLAN).

## 1. Зачем нужно
Коммутатор — основное устройство в любой LAN. Чтобы найти злоумышленника (например, по MAC на принтере), нужно уметь работать с таблицей коммутации и понимать, как изолировать трафик с помощью VLAN.

## 2. Простыми словами
Коммутатор — это умный разветвитель. Он запоминает, за каким портом сидит какой компьютер (по MAC-адресу). Если приходит письмо для ПК1, он не орет на всех, а отправляет его только в нужный порт. VLAN — это когда один физический свитч делим на несколько виртуальных, чтобы бухгалтерия не видела трафик админов.

## 3. Технические детали

### 3.1. MAC-адрес (Media Access Control)
- 48-битный физический адрес (6 байт).
- Записывается в hex (hexadecimal), например: `00:D8:61:F9:B3:27`.
- **Глобальный (UAA):** Уникален в мире (прошит производителем).
- **Локальный (LAA):** Назначается администратором.
- **Индивидуальный (Unicast):** Для одного получателя.
- **Групповой (Multicast):** Для группы.
- **Широковещательный (Broadcast):** `FF:FF:FF:FF:FF:FF`. Все устройства сегмента принимают кадр.
- *OUI:* Первые 3 байта (24 бита) указывают на производителя.

### 3.2. Коммутатор (Switch)
- Работает на L2 (канальный).
- Хранит **таблицу коммутации** (MAC-address table): соответствие MAC-адреса и порта (например, MAC `00-01-11-11-11-11` -> Порт `FastEthernet 1/0/5`).
- Если MAC в таблице есть — передает кадр в конкретный порт.
- Если MAC нет — рассылает кадр во все порты (flooding), пока не получит ответ и не запишет в таблицу.

### 3.3. Топологии
- **Шина:** Все на одном кабеле. Медленно, коллизии.
- **Звезда:** Все к свитчу. Высокая надежность, простота.
- **Полносвязная:** Каждый с каждым. Дорого, но надежно (много путей).

### 3.4. VLAN (Virtual LAN)
- Логическое разделение одного физического коммутатора на несколько виртуальных сетей.
- Устройства в разных VLAN изолированы друг от друга на L2 (не видят друг друга).
- **Типы портов:**
  - **Access:** Смотрит в один VLAN, принимает нетегированные кадры (для конечных ПК).
  - **Trunk:** Соединяет коммутаторы, передает трафик многих VLAN с тегами (802.1Q).
- *Для связи между VLAN нужен маршрутизатор (L3).*

## 4. Пример / команда

```cisco
# Посмотреть таблицу MAC-адресов на свитче (Cisco)
show mac address-table

# Найти конкретный MAC и порт
show mac address-table address 0002.1713.1613
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| ARP-спуфинг (перехват трафика) | Dynamic ARP Inspection (DAI), Port Security |
| MAC Flooding (переполнение таблицы свитча) | Port Security (ограничение MAC на порт) |
| Подключение неавторизованного устройства | 802.1x (аутентификация), Port Security |
| Переход злоумышленника между отделами | VLAN (сегментация), ACL между VLAN |
