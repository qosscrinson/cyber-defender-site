# Периметры безопасности. Средства защиты информации (СЗИ)

> [!abstract] Кратко
> Модель эшелонированной защиты (Defense in Depth). Разбор уровней ИБ от внешнего периметра до сотрудника. Понимание того, какие классы СЗИ применяются на каждом уровне для блокировки атак.

## 1. Зачем нужно
Принцип «эшелонированности» требует защиты на всех уровнях. Если хакер пробил внешний периметр, его должна встретить защита локальной сети. Если прошел и туда — защита ОС и баз данных. Понимание этих уровней позволяет правильно проектировать инфраструктуру.

## 2. Простыми словами
Представь матрешку или луковицу. Снаружи — броня от массовых атак (DDoS). Дальше — стены (файрволы) и сигнализации (IDS/IPS). Внутри — защита конкретных устройств (антивирусы), баз данных (мониторинг) и, наконец, обучение самого человека, так как фишинг пробивает любую технику.

## 3. Технические детали

### 3.1. Внешний периметр
Защищает сеть от атак из интернета:
- **AntiDDoS:** защита от распределенных атак на отказ в обслуживании.
- **AntiBot:** защита от ботов (парсеры, брутфорс, накрутка).
- **WAF (Web Application Firewall):** защита веб-приложений от атак уровня приложений (OWASP Top 10, SQL-инъекции, XSS).
- *Вендоры:* Akamai, CloudFlare, Qrator, NGENIX.

### 3.2. Локальная сеть (Внутренний периметр)
Защита внутри корпоративной сети:
- **FW / NGFW / UTM:** Межсетевые экраны (Firewall). NGFW (Next-Gen) умеют смотреть не только IP/порты, но и приложения.
- **IDS / IPS:** Системы обнаружения (IDS) и предотвращения (IPS) вторжений.
- **NTA:** Анализ сетевого трафика на аномалии.
- **NAT:** Трансляция адресов (скрытие внутренней структуры).
- **VPN:** Безопасный удаленный доступ.
- *Вендоры:* Fortinet, CheckPoint, UserGate, PT NAD.

### 3.3. Виртуализация и микросегментация
Защита внутри виртуальных сред (VMware, K8s):
- **NSX / Service mesh:** Микросегментация сети внутри виртуалок.
- **Kaspersky Security:** Антивирус для виртуальных сред (без агента или легкий агент).

### 3.4. Операционная система (Хосты)
Защита конечных устройств (Windows, Linux):
- **Antivirus / EDR:** Антивирус и системы обнаружения и реагирования на конечных точках.
- **GPO:** Групповые политики (ограничение прав).
- **DLP:** Предотвращение утечек данных.
- **MFA / IAM:** Многофакторная аутентификация и управление доступом.
- **crypto:** Шифрование дисков (preboot).

### 3.5. Базы данных и ПО
- **DBF (Database Firewall):** Файрвол уровня БД.
- **DAM (Database Activity Monitoring):** Мониторинг активности в БД.
- **PAM (Privileged Access Management):** Контроль действий админов (запись сессий).

### 3.6. Сотрудник
Последний рубеж обороны:
- **Awareness:** Повышение осведомленности.
- **Standards:** Доведение норм и правил ИБ.

### 3.7. Глобальный контроль
- **SIEM:** Сбор логов со всех систем, корреляция событий (центр мониторинга).
- **Vulnerability Scanner:** Поиск уязвимостей (сканирование).
- **Pentest (Пентест):** Проверка защищенности руками хакеров (этичный хакинг).

## 4. Пример / команда
Базовый пример сканирования портов с помощью `nmap` (как элемент Vulnerability Scanner / Pentest):

```bash
# Сканирование первых 1000 портов на хосте
nmap -v 192.168.1.1
# Определение версий служб (для поиска уязвимостей)
nmap -sV 192.168.1.1
```

## 5. Для ИБ

| Риск | Защита (Уровень) |
|------|--------|
| DDoS-атака на сайт | Внешний периметр (AntiDDoS) |
| SQL-инъекция на сайте | Внешний периметр (WAF) |
| Проникновение вируса в локальную сеть | Локальная сеть (NGFW, IPS) + ОС (Antivirus/EDR) |
| Кража базы данных инсайдером | Уровень БД (DAM, DBF) + ОС (DLP) |
| Взлом админом базы данных | Уровень БД (PAM) |
| Утечка пароля через фишинг | Сотрудник (Awareness, MFA) |
| Пропуск атаки из-за разрозненных логов | Глобальный (SIEM) |
