# Процесс Awareness (Повышение осведомленности)

> [!abstract] Кратко
> Обучение сотрудников кибергигиене и распознаванию социальной инженерии. Понимание цифрового следа, методов фишинга (фейковые чаты, письма), проведение социотехнических учений и формирование культуры безопасности.

## 1. Зачем нужно
98% кибератак начинаются с человека (соц. инженерия). Никакой WAF или антивирус не спасет, если сотрудник сам перейдет по ссылке и введет пароль на фейковом сайте. Awareness превращает самого уязвимого «человека» в дополнительный сенсор безопасности.

## 2. Простыми словами
Это «прививка» от мошенников. Сотрудников учат не кликать по подозрительным ссылкам, не вводить коды из SMS в сторонних формах и использовать только корпоративные каналы связи. Обучение проходит через статьи, рассылки и «контрольные закупки» — фейковые фишинговые письма, чтобы проверить бдительность.

## 3. Технические детали

### 3.1. Цифровой след (Digital Footprint)
- **Активный:** Пользователь сам оставляет данные (посты, фото, заполнение форм, включение cookie).
- **Пассивный:** Данные собираются без ведома пользователя (IP-адрес, метаданные, история браузера).
- *Зачем знать:* По следу злоумышленники собирают досье для таргетированной атаки (например, знают имя ребенка, чтобы скинуть «конкурс»).

### 3.2. Основные векторы атак на сотрудника
1. **Фейковые рабочие чаты:** Злоумышленники создают группу в WhatsApp/Telegram с названием отдела, ставят фото руководителя. Просят «срочно прислать код из SMS» или перейти по ссылке.
2. **Фишинг в мессенджерах:** Взлом аккаунта коллеги и просьба проголосовать за ребенка в конкурсе (кража учетки Telegram).
3. **Имитация HR/бухгалтерии:** Письма про «индексацию зарплат», «изменение пропусков» или «корпоративный VPN».

### 3.3. Методы повышения Awareness
- **Пассивные:** Статьи на портале, посты в корп. мессенджере, рассылки, обязательные курсы в СДО (например, «Основы цифровой гигиены»).
- **Активные:** Социотехнические учения (рассылка фейковых писем). Цель — замерить процент кликнувших и провести работу над ошибками.

### 3.4. Статистика учебных кампаний (пример)
- *12 кампаний:* 9607 писем отправлено.
- *Результат:* 1183 перешли по ссылке, **757 паролей скомпрометировано**.
- *Топ приманок:*
  - «Замена пропусков» (225 паролей).
  - «Корпоративный VPN» (134 пароля).
  - «Приказ о премировании» (28 паролей).

## 4. Пример / команда
Как быстро проверить подозрительный домен из фишингового письма (без перехода на него):

```bash
# Получить информацию о домене (кто владелец, дата регистрации)
whois suspicious-domain.com
# Если домен зарегистрирован 2 дня назад — это 100% фишинг.
```

## 5. Для ИБ

| Риск | Защита (Awareness) |
|------|--------|
| Переход по фишинговой ссылке | Социотехнические учения, обучение распознаванию URL |
| Кража аккаунта через фейковый чат | Запрет на передачу кодов/паролей, использование корп. мессенджеров |
| Утечка данных через цифровой след | Курсы по цифровой гигиене, настройки приватности |
| Ввод пароля на фейковой странице | Внедрение MFA (даже если украдут пароль, без кода не войдут) |
| Паника и сокрытие факта клика | Создание доверительной среды (лучше сообщить в СБ, чем скрыть) |

4. Почему мошенники используют тему «премии» или «замены пропусков»? Что они эксплуатируют?
5. Какие правила безопасности нужно соблюдать при общении в рабочих чатах Telegram/WhatsApp?
