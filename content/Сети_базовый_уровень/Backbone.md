# Backbone

> [!abstract] Кратко
> Магистральные сети — высокоскоростные каналы между крупными узлами. Оптоволокно (DWDM, 400G+), подводные кабели, междугородние и международные линии. Обеспечивают устойчивость: при отказе линии трафик идёт по другим маршрутам.

## 1. Зачем нужно
Понять физический «скелет» интернета — то, по чему реально идёт трафик между континентами.

## 2. Простыми словами
Междугородние трассы: широкие, быстрые, с объездами. Одна закрыта — едешь по другой.

## 3. Технические детали

- **Backbone** — высокоскоростные магистрали между крупными узлами.
- **Технологии:** оптоволокно (DWDM, 400G+), подводные кабели, междугородние и международные линии.
- **Устойчивость:** при отказе линии трафик идёт по другим маршрутам.
- **Оборудование:**

| Тип | Примеры |
|---|---|
| Магистральные маршрутизаторы | Cisco ASR, Juniper MX, Huawei NE |
| Коммутаторы | Arista, Cisco Nexus |
| Трансиверы | QSFP, до 400 Гбит/с+ |
| Подводные кабели | MAREA (США–Европа, 160 Тбит/с) |

Схема:

```mermaid
flowchart LR
    C1["Город 1<br/>крупный узел"] ===|оптоволокно 400G| C2["Город 2<br/>крупный узел"]
    C1 ===|резервный путь| C3["Город 3"]
    C3 ===|резервный путь| C2
    C2 ===|подводный кабель| C4["Континент 2"]
```

- **Читать схему:** между узлами — несколько путей. Отказ одного не рвёт связь, трафик идёт по резерву.

## 4. Пример / команда
Проверка пути через магистраль:

```bash
tracert 8.8.8.8
mtr 8.8.8.8         # Linux: потери по хопам
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| Подводный кабель повреждён → отказ региона | Резервные маршруты, геораспределение |
| Нет шифрования на магистрали | MACsec, IPsec |
| Физический доступ к кабелю | Охрана, мониторинг, OTDR |
| Нет резерва → единая точка отказа | Дублирование путей, BGP-переключение |
