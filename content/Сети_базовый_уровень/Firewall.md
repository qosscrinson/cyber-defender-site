# Firewall

> [!abstract] Кратко
> Система фильтрации трафика между зонами. Методы: по IP/портам, по протоколам, stateful-проверка. Типы: аппаратные, программные, облачные.

## 1. Зачем нужно
Понять, чем контролируется трафик между зонами (интернет, DMZ, LAN).

## 2. Простыми словами
Охранник на двери: пропускает только тех, кто в списке, и только туда, куда разрешено.

## 3. Технические детали

**Методы фильтрации:**

- по IP-адресам и портам;
- по протоколам (TCP, UDP, ICMP);
- **stateful-проверка** — отслеживание состояния сессий TCP (входящий пакет — ответ на исходящий).

**Типы:**

| Тип | Пример | Назначение |
|---|---|---|
| Аппаратные | Маршрутизаторы с безопасностью | Корпоративные сети |
| Программные | Windows Defender Firewall | Персональная защита |
| Облачные | AWS WAF | Защита веб-приложений от DDoS |

| ✅ Плюсы | ❌ Минусы |
|---|---|
| Защита внутренней сети | Усложнение настройки |
| Контроль трафика | Риск ошибок в правилах |

## 4. Пример / команда
Правила на Linux:

```bash
iptables -L -n -v
ufw status verbose
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| Слишком широкое правило `any-any` | Явные разрешения, default deny |
| Нет stateful → пропуск чужих пакетов | Stateful-проверка |
| Ошибка в правиле → дыра | Ревизия правил, тесты |
| Нет логирования | Логи firewall, SIEM |
