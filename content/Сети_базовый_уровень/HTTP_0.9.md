# HTTP 0.9

> [!abstract] Кратко
> Первая версия HTTP (1991). Одна строка запроса `GET /path`, ответ — только HTML без заголовков. Только метод GET, только HTML, без кодов статуса.

## 1. Зачем нужно
Понять точку отсчёта, от которой выросли все последующие версии. Без этого не ясно, что именно добавляли версии 1.0 и далее.

## 2. Простыми словами
Первый HTTP — это «дай файл» без всяких формальностей. Просишь — получаешь HTML. Всё.

## 3. Технические детали

**Запрос:**
```text
GET /page.html
```

**Ответ:** чистый HTML без заголовков.

**Ограничения:**
- Только метод `GET`.
- Нет заголовков — ни метаданных, ни кодов статуса.
- Только HTML — картинки и другие типы не поддерживаются.
- Ошибки отдаются как HTML-текст внутри ответа.

## 4. Пример / команда
Такой протокол больше нигде не работает, но увидеть запрос можно в любом текстовом протоколе:

```bash
telnet example.com 80
GET /page.html
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| Нет кодов статуса → нельзя диагностировать | Современные версии HTTP |
| Серверы с поддержкой старых версий | Отключить поддержку 0.9/1.0 |
