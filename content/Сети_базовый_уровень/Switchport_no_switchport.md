# Switchport_no_switchport

> [!abstract] Кратко
> `switchport` — порт в режиме L2 (access/trunk), коммутация внутри VLAN. `no switchport` — порт становится маршрутизируемым L3-интерфейсом с IP. Применяется на Distribution и Core.

## 1. Зачем нужно
Понять, как один и тот же физический порт переключается между L2 и L3. Без этого не ясна разница между коммутатором и маршрутизатором на практике.

## 2. Простыми словами
`switchport` — порт работает как разветвитель внутри комнаты. `no switchport` — порт становится дверью с адресом, через которую ходят в другие сети.

## 3. Технические детали

| Команда | Режим | Где применяется |
|---|---|---|
| `switchport` | L2 (access/trunk) | Уровень доступа |
| `no switchport` | L3 (маршрутизируемый) | Уровень агрегации и ядра |

- **`switchport`:** коммутация кадров по MAC, VLAN, теги.
- **`no switchport`:** порт получает IP, участвует в маршрутизации, как интерфейс роутера.
- **Переключение обратимо:** можно вернуть `switchport`.

## 4. Пример / команда
L3-интерфейс на коммутаторе:

```bash
interface GigabitEthernet0/24
 no switchport
 ip address 192.168.1.1 255.255.255.0
 no shutdown
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| L3-порт без ACL → открытая маршрутизация | ACL на интерфейсе |
| Случайный `no switchport` → потеря VLAN | Ревизия конфигурации, бэкап |
| L3-порт в management-сети | Отдельная management-VLAN, ACL |
| Нет логирования маршрутизируемых портов | NetFlow на L3-порту |
