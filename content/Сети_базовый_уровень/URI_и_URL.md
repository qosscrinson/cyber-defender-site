# URI_и_URL

> [!abstract] Кратко
> URI (Uniform Resource Identifier) — универсальный идентификатор ресурса. URL (Uniform Resource Locator) — частный случай URI, указывающий точное местоположение ресурса в сети.

## 1. Зачем нужно
Чтобы однозначно идентифицировать и находить ресурсы в интернете. Без этого браузер не знал бы, куда идти за страницей.

## 2. Простыми словами
*   **URI** — это «Имя вещи». Оно может быть любым (например, номер ISBN у книги).
*   **URL** — это «Адрес вещи». Он говорит, как ее найти (город, улица, дом).

## 3. Технические детали

| Характеристика | URI | URL |
|---|---|---|
| Назначение | Указывает ресурс или его имя | Указывает точное местоположение |
| Тип | Общий идентификатор (включает URL и URN) | Специфический тип URI |
| Пример | `urn:isbn:0451450523` | `https://example.com/page.html` |
| Протокол | Может отсутствовать (URN) | Содержит (HTTP, FTP и т.д.) |
| Доступ | Не всегда позволяет получить ресурс | Всегда указывает способ доступа |
