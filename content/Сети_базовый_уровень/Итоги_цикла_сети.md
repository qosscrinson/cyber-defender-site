# Итоги_цикла_сети

> [!abstract] Кратко
> Цикл из 5 частей: устройства и топологии → адресация и VLAN → маршрутизация и Proxy ARP → глобальные сети и операторы → IPv6, SDN, Overlay. Ключевые выводы по каждому уровню.

## 1. Зачем нужно
Собрать всё в одну карту — чтобы видеть связи между темами, а не набор фактов.

## 2. Простыми словами
Оглавление всего цикла: от кабеля в квартире до подводных магистралей.

## 3. Технические детали

| Часть | Тема | Ключевые заметки |
|---|---|---|
| 1 | Устройства, топологии | Коммутатор_L2, Коммутатор_L3, Маршрутизатор, ARP |
| 2 | Адресация, VLAN | Маска_Подсети, Сегментация_Сети, VLAN |
| 3 | Маршрутизация | Маршрутизация, Proxy_ARP, Super_VLAN, Router_on_a_Stick |
| 4 | Глобальные сети | LAN_MAN_WAN, BGP, Иерархия_операторов_Tier, Clos |
| 5 | IPv6, SDN, Overlay | IPv6, SDN, SD_WAN, Overlay_сети |

**Главные выводы:**

1. Коммутация — внутри LAN, маршрутизация — между сетями.
2. При маршрутизации MAC меняются, IP не меняются (без NAT).
3. VLAN сегментируют L2, маски — L3, маршрутизация связывает.
4. Интернет — не одна сеть, а миллионы AS, связанных BGP.
5. BGP на доверии → угоны префиксов.
6. IPv6 решает дефицит адресов, но переход затянулся.
7. SDN централизует управление, Overlay строит сеть поверх сети.

## 4. Пример / команда
Проверка своих знаний:

```bash
ping 8.8.8.8
tracert 8.8.8.8
show ip route
```
