# Коммутатор_L2

> [!abstract] Кратко
> Коммутатор L2 работает на канальном уровне, ведёт MAC-таблицу и передаёт кадры только в нужный порт. Не маршрутизирует между VLAN/подсетями.

## 1. Зачем нужно
Понять базовое устройство LAN: как кадр находит порт, почему MAC-таблица важна, чем L2 отличается от хаба.

## 2. Простыми словами
Коммутатор — умный разветвитель: запоминает, за каким портом какой MAC, и отдаёт кадр только туда. Хаб кричал во все порты, коммутатор — адресно.

## 3. Технические детали
- **Уровень:** L2 (канальный).
- **Таблица:** MAC → порт, обучается по source MAC входящих кадров.
- **Поведение при пустой таблице:** flood на все порты, кроме входного (как хаб).
- **Ограничение:** не маршрутизирует между VLAN/подсетями.
- **Плюсы:** простая настройка, высокая производительность.
- **Минусы:** нет IP-адресации, не подходит для сложных сетей с VLAN.

## 4. Пример / команда
Просмотр MAC-таблицы:

```bash
show mac address-table
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| MAC-flooding → таблица переполнена → flood | Port Security, лимит MAC на порт |
| Подмена MAC → перехват | Port Security, DHCP Snooping |
| Неизвестный MAC → flood → утечка кадра | Статические записи для критичных портов |
| Хаб вместо коммутатора → коллизии | Заменить на L2-коммутатор |
