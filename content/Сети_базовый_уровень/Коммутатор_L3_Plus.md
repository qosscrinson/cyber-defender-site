# Коммутатор_L3_Plus

> [!abstract] Кратко
> Расширенный L3-коммутатор: полноценная динамическая маршрутизация (OSPF, BGP, EIGRP), ACL, QoS, NAT, иногда MPLS. Приближен к маршрутизатору по функциям.

## 1. Зачем нужно
Понять границу между L3-коммутатором и L3+: где заканчивается статика и начинается динамика, зачем MPLS.

## 2. Простыми словами
L3+ — это L3-коммутатор, который умеет то же, что маршрутизатор, но остаётся коммутатором по скорости внутри LAN.

## 3. Технические детали
- **Уровень:** L3 и выше.
- **Динамическая маршрутизация:** [[Протокол_OSPF|OSPF]], [[Протокол_BGP|BGP]], EIGRP.
- **Управление трафиком:** ACL, QoS, NAT.
- **MPLS:** в некоторых моделях для оптимизации.
- **Плюсы:** динамика, высокий уровень управления.
- **Минусы:** стоимость, сложность настройки.

## 4. Пример / команда
Включение OSPF:

```bash
router ospf 1
 network 192.168.10.0 0.0.0.255 area 0
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| OSPF без аутентификации → подмена маршрутов | OSPF MD5/SHA аутентификация |
| BGP без фильтрации → утечка префиксов | Prefix-list, route-map |
| MPLS без контроля → туннель в обход | Контроль LSP, ACL на границе |
| QoS без политики → приоритет атакующему | Явные class-map, policy-map |
