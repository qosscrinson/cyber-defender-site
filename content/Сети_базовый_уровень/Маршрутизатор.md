# Маршрутизатор

> [!abstract] Кратко
> Устройство L3 и выше: соединяет разные сети, поддерживает IPv4/IPv6, VPN, NAT, часть функций межсетевого экрана. Не заменяет коммутатор внутри LAN.

## 1. Зачем нужно
Понять, чем router отличается от L3-коммутатора: WAN, безопасность, задержки, граница применения.

## 2. Простыми словами
Маршрутизатор — пограничник между сетями. Умеет в WAN, VPN, NAT. Внутри LAN его заменяет коммутатор.

## 3. Технические детали
- **Уровень:** L3 и выше.
- **Функции:** маршрутизация IPv4/IPv6, VPN, NAT, часть межсетевого экранирования.
- **Плюсы:** WAN, высокий уровень безопасности.
- **Минусы:** не для высокоскоростного L2, может добавлять задержки в LAN.

## 4. Пример / команда
Просмотр маршрутов и NAT:

```bash
show ip route
show ip nat translations
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| NAT без контроля → скрытый доступ | Логирование NAT, ACL |
| VPN без сильной аутентификации | IKEv2, сертификаты, MFA |
| Маршрут по умолчанию в интернет без фильтра | ACL на WAN, zone-based firewall |
| Открытый доступ к управлению | Ограничить управление по IP, SSH вместо Telnet |
