# Модель_TCP_IP

> [!abstract] Кратко
> Рабочая 4-уровневая модель современного интернета. Объединяет некоторые уровни эталонной модели [[Модель_OSI]].

## 1. Зачем нужно
Описывает реальное взаимодействие в современных сетях. Именно по этой модели работает весь интернет, в отличие от теоретической OSI.

## 2. Простыми словами
Это упрощённая версия OSI. Сетевики общаются терминами OSI, но железо и софт в реальности работают по TCP/IP. Некоторые уровни в ней просто склеены.

## 3. Технические детали
Состоит из 4 уровней:

1. **Канальный** (объединяет L1 и L2 OSI).
2. **Межсетевой** (идентичен L3 OSI).
3. **Транспортный** (идентичен L4 OSI).
4. **Прикладной** (объединяет L5, L6 и L7 OSI).

| OSI (7 уровней) | TCP/IP (4 уровня) |
| :--- | :--- |
| L7 Прикладной | Прикладной (L5–L7) |
| L6 Представительный | Прикладной (L5–L7) |
| L5 Сеансовый | Прикладной (L5–L7) |
| L4 Транспортный | Транспортный |
| L3 Сетевой | Межсетевой |
| L2 Канальный | Канальный (L1–L2) |
| L1 Физический | Канальный (L1–L2) |

## 4. Пример / команда
Стек протоколов TCP/IP лежит в основе работы любого устройства в интернете: от смартфона до магистрального роутера.

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| Смешение уровней при настройке межсетевых экранов | Чёткое понимание, на каком уровне (межсетевом или прикладном) фильтрует трафик конкретное устройство |
| Сложность отладки из-за объединения уровней | Использование анализатора трафика (Wireshark) для просмотра инкапсуляции |
