# Плоская_сеть

> [!abstract] Кратко
> Все устройства в одной сети без разделения на зоны. Плюсы: простота, низкие затраты. Минусы: нулевая безопасность, broadcast замедляет, нельзя изолировать сервисы. Где: дом, тестовые среды.

## 1. Зачем нужно
Понять точку отсчёта — от неё видно, зачем DMZ и сегментация.

## 2. Простыми словами
Одна большая комната: все слышат всех, один загорелся — горит всё.

## 3. Технические детали

| ✅ Плюсы | ❌ Минусы |
|---|---|
| Простота | Нулевая безопасность |
| Низкие затраты | Broadcast замедляет работу |
| — | Нельзя изолировать сервисы |

- **Взлом одного устройства** ставит под угрозу всю сеть.
- **Где:** домашние сети, тестовые среды, где безопасность не важна.

## 4. Пример / команда
Проверка плоскости:

```bash
arp -a              # все видят всех
ping 192.168.1.x    # любой доступен
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| Боковое перемещение | Сегментация, VLAN |
| Broadcast-шторм | Малые broadcast-домены |
| Нет изоляции сервисов | DMZ, отдельные подсети |
| Один взлом → вся сеть | Zero Trust, микросегментация |
