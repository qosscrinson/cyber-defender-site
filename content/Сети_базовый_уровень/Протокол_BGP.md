# Протокол_BGP

> [!abstract] Кратко
> Протокол динамической маршрутизации (EGP), управляющий обменом маршрутами между автономными системами (AS). Основной протокол маршрутизации в Интернете.

## 1. Зачем нужно
Для связи между разными сетями (провайдерами, крупными компаниями). BGP выбирает пути не по скорости, а по административным и политическим правилам (например, «трафик в США пускать через Лондон, а не через Франкфурт»).

## 2. Простыми словами
Это «дипломатия» интернета. Роутеры разных стран и компаний договариваются друг с другом, какие маршруты они готовы предоставить и по каким правилам.

## 3. Технические детали
*   **Тип:** Path-vector (вектор путей).
*   **Транспорт:** TCP, порт **179**.
*   **Сессии:** 
    *   `eBGP` — между разными AS.
    *   `iBGP` — внутри одной AS.
*   **Типы сообщений:** `OPEN` (установка), `UPDATE` (маршруты), `NOTIFICATION` (ошибки), `KEEPALIVE` (поддержка сессии).
*   **Состояния сессии:** Idle → Connect → Active → OpenSent → OpenConfirm → Established.
*   **Метрики (Атрибуты):** Вместо Cost используются атрибуты. Главные: Weight, Local Preference, AS-Path, Origin, MED.
*   **Алгоритм выбора пути (Best Path):** 
    1. Наибольший Weight (локальный).
    2. Наибольшая Local Preference.
    3. Самый короткий AS-Path (сколько автономных систем нужно пройти).
    4. Наименьший Origin (IGP > EGP > Incomplete).
    5. Наименьший MED.
    6. Предпочтение eBGP над iBGP.

## 4. Пример / команда
Проверка соседей и таблицы BGP (Cisco):
```text
show ip bgp summary
show ip bgp
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| **BGP Hijacking** (злоумышленник анонсирует чужие IP-префиксы, чтобы перехватить трафик, как было с YouTube в 2008) | Использование RPKI (Resource Public Key Infrastructure), фильтрация префиксов (prefix-list) и max-prefix |
| **Отсутствие аутентификации** (подмена TCP-сессии) | Настройка TCP MD5 Signature (или TCP-AO) для защиты сессий BGP |
| **Утечка маршрутов (Route Leak)** (ошибка админа, которая заваливает трафиком чужую сеть) | Строгая фильтрация анонсов на границе (route-maps, prefix-lists) |
