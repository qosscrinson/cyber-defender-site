# Протокол_DHCP

> [!abstract] Кратко
> Прикладной протокол (L7), автоматически назначающий IP-адреса и другие сетевые параметры (маску, шлюз, DNS) подключаемым устройствам.

## 1. Зачем нужно
Избавляет системных администраторов от ручной настройки IP-адресов на каждом компьютере. Устройство подключается к сети и автоматически получает все нужные настройки.

## 2. Простыми словами
Это «администратор гостиницы». Ты заселяешься (подключаешься к сети), он выдает тебе ключ (IP-адрес) и говорит, где находится столовая (шлюз) и справочная (DNS). Когда ты уходишь, ключ возвращается.

## 3. Технические детали
*   **Уровень:** L7 (Прикладной). **Транспорт:** UDP (порты 67 и 68).
*   **Процесс DORA (4 шага):**
    1. **D**iscover: Клиент шлет широковещательный запрос на поиск DHCP-сервера.
    2. **O**ffer: Сервер предлагает доступный IP-адрес.
    3. **R**equest: Клиент выбирает адрес и запрашивает его.
    4. **A**ck: Сервер подтверждает назначение.
*   **Продление аренды (lease):**
    *   Через **50%** времени аренды клиент отправляет DHCP REQUEST для продления.
    *   Если сервер не отвечает, через **87%** времени клиент шлет широковещательный DISCOVER для получения нового адреса.
    *   При отключении отправляется сообщение RELEASE.
*   **Передаваемые параметры:** IP-адрес, маска подсети, шлюз по умолчанию, DNS-серверы, время аренды.

## 4. Пример / команда
Просмотр текущей конфигурации и запрос нового адреса в Windows:

```bash
ipconfig /all
ipconfig /release
ipconfig /renew
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| **DHCP-спуфинг** (поднятие злоумышленником своего DHCP-сервера, который выдаст клиентам ложный шлюз для перехвата трафика) | DHCP Snooping на коммутаторах (доверие только легитимному порту) |
| **Исчерпание пула адресов (DHCP Starvation)** (атакующий запрашивает тысячи адресов поддельными MAC-адресами) | Port Security (ограничение количества MAC-адресов на порту), привязка IP-MAC |
