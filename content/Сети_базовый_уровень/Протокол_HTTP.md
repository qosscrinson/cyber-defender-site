# Протокол_HTTP

> [!abstract] Кратко
> Протокол прикладного уровня (L7) для обмена данными между клиентом и сервером. Лежит в основе Всемирной паутины (WWW). Работает по модели «запрос-ответ» и по умолчанию не сохраняет состояние.

## 1. Зачем нужно
Для передачи гипертекста (HTML), изображений, видео и других данных. Позволяет браузеру запрашивать ресурсы у сервера, а серверу — отдавать их.

## 2. Простыми словами
Это язык общения браузера и сервера. Ты говоришь: «Дай мне страницу», сервер отвечает: «Вот она» (или «Не найдено»). Вся навигация в интернете построена на этом.

## 3. Технические детали
- **Уровень:** L7 (прикладной).
- **Архитектура:** клиент-сервер.
- **Состояние:** stateless (без сохранения состояния). Сервер не помнит предыдущие запросы. Для «памяти» используются Cookies и Сессии.
- **Формат:** текстовый (человекочитаемый), что упрощает отладку.
- **Гипертекст:** текст со ссылками на другие ресурсы (ключевая технология WWW).

## 4. Пример / команда
Просмотр HTTP-заголовков ответа сервера через curl:

```bash
curl -I https://example.com
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| Перехват данных (HTTP передаёт данные в открытом виде) | Использование HTTPS (шифрование TLS) |
| Отсутствие аутентификации (клиент не проверяет, тот ли это сервер) | HTTPS + сертификаты |
| XSS / SQLi (атаки через внедрение кода в запросы) | WAF, валидация входных данных |
