# Протокол_ICMP

> [!abstract] Кратко
> Служебный протокол сетевого уровня (L3) для передачи сообщений об ошибках и диагностики сети. Не используется для передачи пользовательских данных.

## 1. Зачем нужно
Сообщает об ошибках при передаче IP-пакетов (например, «хост недоступен») и используется для проверки связи (ping, traceroute).

## 2. Простыми словами
Это «система оповещения». Если почтальон (IPv4) не может доставить письмо, он отправляет тебе открытку (ICMP) с текстом: «Адресат выбыл» или «Ящик переполнен».

## 3. Технические детали
- **Уровень:** L3 (инкапсулируется после заголовка IPv4, идентифицируется как протокол 1).
- **Структура:** 8-битный заголовок + данные переменного размера.
- **Поле Type (основные):**
    - `8` — запрос ICMP echo (ping).
    - `0` — ответ ICMP echo (ping).

## 4. Пример / команда
Проверка связи с узлом (отправка ICMP Echo Request):

```bash
ping 8.8.8.8
tracert google.com
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| ICMP-флуд (DDoS-атака, забивание канала) | Ограничение скорости (rate limiting) ICMP на межсетевом экране |
| Ping of Death (отправка пакетов аномально большого размера) | Блокировка фрагментированных ICMP-пакетов |
| Разведка сети (использование ping для поиска живых хостов) | Отключение ответов на ICMP Echo Request на периметре |
