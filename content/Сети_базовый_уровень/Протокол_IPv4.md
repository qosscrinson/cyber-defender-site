# Протокол_IPv4

> [!abstract] Кратко
> Основной протокол сетевого уровня (L3) для межсетевого взаимодействия с коммутацией пакетов. Используется в интернете и локальных сетях.

## 1. Зачем нужно
Обеспечивает логическую адресацию и маршрутизацию пакетов между разными сетями. Позволяет объединить миллиарды устройств в единую глобальную сеть.

## 2. Простыми словами
Это «почтовая система» интернета. Он берёт данные, упаковывает их в конверты (пакеты) и пишет на них адрес отправителя и получателя (IP-адреса).

## 3. Технические детали
- **Уровень:** L3 (сетевой).
- **Типы полезной нагрузки (инкапсулируемые протоколы):**
    - [[Протокол_ICMP]] — управляющие сообщения.
    - [[Протокол_IGMP]] — управление группами (multicast).
    - [[Протокол_TCP]] — надёжная передача.
    - [[Протокол_UDP]] — быстрая передача.
    - [[Протокол_SCTP]] — потоковая передача.

## 4. Пример / команда
Проверка IP-адреса и маршрута:

```bash
ipconfig
ip route
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| IP-спуфинг (подмена IP-адреса источника) | Ingress/Egress фильтрация на маршрутизаторах (uRPF) |
| Фрагментация пакетов (используется для обхода IDS) | Сборка фрагментов на межсетевом экране перед передачей в сеть |
