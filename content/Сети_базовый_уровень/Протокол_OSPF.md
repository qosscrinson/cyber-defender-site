# Протокол_OSPF

> [!abstract] Кратко
> Протокол динамической маршрутизации (IGP), основанный на состоянии канала (link-state). Использует алгоритм Дейкстры для поиска кратчайшего пути внутри одной автономной системы (AS).

## 1. Зачем нужно
Для автоматического обмена маршрутной информацией между маршрутизаторами внутри одной сети (например, внутри компании или провайдера). Быстро реагирует на изменения топологии.

## 2. Простыми словами
Каждый роутер составляет карту всей сети и знает, где кто находится. Если один кабель порвался, роутеры быстро пересчитывают маршруты по алгоритму Дейкстры и находят обходной путь. «OSPF — это система умных светофоров. Роутеры сами обмениваются картами сети (LSA), договариваются о соседстве (Hello) и мгновенно пересчитывают маршруты (Алгоритм Дейкстры), если где-то оборвался кабель. Работает внутри одной компании».

## 3. Технические детали
*   **Алгоритм:** SPF (Shortest Path First) по Дейкстре.
*   **Транспорт:** Работает напрямую поверх IP (протокол №89). **Не использует TCP/UDP**. Надежность обеспечивается собственными механизмами подтверждений.
*   **Процесс работы:**
    1. Установка соседства (пакеты **Hello**).
    2. Обмен информацией о каналах (LSA).
    3. Построение базы LSDB.
    4. Расчет маршрутов и заполнение таблицы.
*   **Типы пакетов:** Hello, DBD (Database Description), LSR (Request), LSU (Update), LSAck (Acknowledgment).
*   **Состояния:** Down → Init → Two-Way → ExStart → Exchange → Loading → Full. (Для NBMA-сетей есть состояние Attempt).
*   **DR и BDR (Designated / Backup Router):** Выбираются в сетях с общим каналом (Ethernet), чтобы не передавать LSA каждому роутеру (снижение нагрузки).
*   **Метрика (Cost):** Рассчитывается по формуле `10^8 / Пропускная способность`. Чем выше скорость канала, тем ниже стоимость (Cost) и тем приоритетнее маршрут.

## 4. Пример / команда
Проверка соседей и базы OSPF (Cisco):
```text
show ip ospf neighbor
show ip ospf database
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| **OSPF-спуфинг** (отправка ложных Hello-пакетов для создания несуществующих соседей) | Аутентификация OSPF (MD5 или SHA) на всех интерфейсах |
| **Внедрение ложных маршрутов** (атакующий пытается стать шлюзом) | Пассивные интерфейсы (passive-interface) там, где OSPF не нужен, строгая фильтрация на границах |
