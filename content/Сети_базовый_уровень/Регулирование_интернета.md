# Регулирование_интернета

> [!abstract] Кратко
> Эволюция: ARPANET (без LAN/WAN, IMP-устройства) → коммерческий интернет → Ethernet, LAN-технологии, коммутаторы вместо IMP, IP-адреса. Управление — иерархия ICANN → IANA → RIR → LIR → ISP → потребители.

## 1. Зачем нужно
Понять, откуда взялся интернет и кто им управляет. Без истории не ясна логика иерархии.

## 2. Простыми словами
Сначала был один большой эксперимент (ARPANET). Потом он стал коммерческим, оброс городами (LAN) и дорогами между ними (WAN). Управление — как у города: мэрия, кадастр, районы.

## 3. Технические детали

**Эволюция:**

| Этап | Что было |
|---|---|
| ARPANET | Без LAN/WAN, IMP-устройства |
| Коммерческий интернет | Переход к массовому использованию |
| Современность | Ethernet, LAN-технологии, коммутаторы вместо IMP, IP-адреса |

**Кто регулирует:**

| Уровень | Организация | Роль |
|---|---|---|
| Вершина | ICANN | Доменные имена и IP |
| Администрация | IANA | Адресное пространство |
| Региональные | RIR | Номера AS |
| Локальные | LIR | Блоки от RIPE NCC, IP клиентам |
| Провайдеры | ISP | Подключение |
| Потребители | Мы | Платим за доступ |

## 4. Пример / команда
Проверка истории (косвенно):

```bash
whois -h whois.iana.org 8.8.8.8
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| Нет понимания иерархии → сложно найти виновного | Документация, схема RIR/LIR/ISP |
| Слабый контроль домена у регистратора | 2FA, lock, мониторинг |
| Нет аудита выдачи AS/IP | RPKI, ROA, реестр |
| Политические риски (санкции, блокировки) | Резервные AS/IP, диверсификация |
