# Сеть_Подсеть

> [!abstract] Кратко
> Сеть — группа устройств для обмена данными. Подсеть — логическая часть сети, отделённая маской. Деление на подсети уменьшает трафик, повышает безопасность и упрощает управление.

## 1. Зачем нужно
Понять разницу между «сеть» и «подсеть» до того, как браться за маску. Без этого маска — просто число.

## 2. Простыми словами
Сеть — это улица. Подсеть — квартал внутри улицы. Маска — забор, который показывает, где кончается квартал.

## 3. Технические детали

| Понятие | Что это | Пример |
|---|---|---|
| Сеть | Группа устройств | Домашняя Wi-Fi |
| Подсеть | Часть сети, отделённая маской | 192.168.1.0/24 |
| Маска | Граница сети/хоста | 255.255.255.0 |

- **Зачем делить:** меньше широковещательного трафика, изоляция отделов, проще управлять, независимая логика от физики.
- **Пример:** офис — бухгалтерия 192.168.1.0/24, ИТ 192.168.2.0/24. Между ними — маршрутизатор.
- **Без деления:** одна плоская сеть, ARP-шторм, любой видит любого.

## 4. Пример / команда
Проверка своей сети и маски:

```bash
ipconfig /all      # Windows: IP, маска, шлюз
ip addr show       # Linux
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| Плоская сеть → любой видит любого | Деление на подсети, ACL между ними |
| Широковещательный шторм | Меньше хостов в подсети |
| Нет изоляции гостей | Отдельная подсеть для гостей |
| Сложная диагностика в большой сети | Малые подсети, понятная схема |
