# Среды передачи данных (L1)

> [!abstract] Кратко
> Обзор технологий физического уровня (L1) модели OSI: от медных кабелей и разъемов до оптоволокна и радиоволн. Определяет, как нули и единицы физически передаются между устройствами.

## 1. Зачем нужно
Физический уровень — это фундамент. Если кабель поврежден, разъем неисправен или Wi-Fi глушится, никакие протоколы верхних уровней (IP, TCP) не спасут. Понимание L1 необходимо для физической безопасности и траблшутинга.

## 2. Простыми словами
Это то, что можно потрогать руками. Розетки, провода, антенны. L1 определяет, как электричество превращается в биты, а радиоволны — в интернет.

## 3. Технические детали (Обзор технологий)

| Технология | Что это | Особенности |
| :--- | :--- | :--- |
| **RJ45** | Стандартный сетевой разъем (8P8C) | Втыкается в роутер/ПК, основа проводных LAN. |
| **100BASE-TX** | Ethernet на 100 Мбит/с | Витая пара (Cat5+). Обычный «интернет-кабель». |
| **802.11** | Семейство стандартов Wi-Fi | Радиоэфир, беспроводные локальные сети. |
| **RS-232** | Последовательный порт (COM) | Медленно, но надежно. Используется для консольного доступа к железкам. |
| **V.34** | Модемный протокол | До 33,6 кбит/с по телефонной линии (dial-up). Устарел. |
| **DSL** | Цифровая абонентская линия | Интернет через телефонный провод (без прокладки нового кабеля). |
| **SDH** | Синхронная цифровая иерархия | Магистральный оптический транспорт операторов связи, с резервированием путей. |

## 4. Пример / команда
Проверка физического линка (мигают ли индикаторы на сетевой карте):
```bash
ip link show
```

## 5. Для ИБ

| Риск | Что делает атакующий | Защита |
|------|----------------------|--------|
| **Несанкционированное подключение** | Втыкает кабель в свободный RJ45-порт и получает доступ в LAN. | Port Security, MAC-фильтрация, 802.1X, отключение неиспользуемых портов. |
| **Атаки на Wi-Fi** | Глушение эфира, поддельные точки доступа, перехват WPA. | WPA3, контроль эфира, сегментация гостевых сетей. |
| **Физический доступ к консоли** | Подключение к RS-232 на оборудовании для сброса пароля. | Пломбирование портов, физическая охрана. |
| **Устаревшие dial-up/V.34** | Wardialing (перебор номеров) для поиска бэкдоров. | Инвентаризация и отключение неиспользуемых модемов. |
| **Перехват на линии** | Прослушивание медной пары (DSL/100BASE-TX). | Экранированные кабели, шифрование выше по стеку (VPN). |
