# Статическая_Маршрутизация

> [!abstract] Кратко
> Администратор вручную прописывает маршруты. Плюсы: простота, контроль, надёжность. Минусы: не масштабируется, при отказе маршрута — ручная замена.

## 1. Зачем нужно
Понять базовый способ маршрутизации — с него начинают все сети. Без статики не объяснить динамику.

## 2. Простыми словами
Сам нарисовал карту дорог и положил на стол. Пока дороги не меняются — работает. Дорогу закрыли — идёшь перерисовывать вручную.

## 3. Технические детали

- **Команда:** `ip route <сеть> <маска> <next-hop>`
- **Пример:** `ip route 192.168.2.0 255.255.255.0 192.168.1.1` — в сеть 192.168.2.0/24 идти через 192.168.1.1.
- **Плюсы:** простота, полный контроль, высокая надёжность (маршруты не меняются сами).
- **Минусы:** низкая масштабируемость, ручная замена при отказе, возможен простой.

## 4. Пример / команда
Настройка статического маршрута:

```bash
ip route 192.168.2.0 255.255.255.0 192.168.1.1
show ip route static
```
