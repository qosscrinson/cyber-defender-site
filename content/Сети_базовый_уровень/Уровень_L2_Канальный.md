# Уровень_L2_Канальный

> [!abstract] Кратко
> Уровень [[Модель_OSI]], обеспечивающий надёжную передачу данных внутри одной локальной подсети через коммутаторы с использованием MAC-адресов.

## 1. Зачем нужно
Обеспечивает надёжную передачу данных через физический канал. Включает задачи по обнаружению и исправлению ошибок, а также управление доступом к среде передачи.

## 2. Простыми словами
Передача данных внутри одной локальной сети (LAN) с помощью коммутатора. Коммутатор не смотрит на IP-адреса, он знает только MAC-адреса.

## 3. Технические детали
- **Функции:** кадрирование, физическая адресация (MAC), обнаружение ошибок, управление доступом к среде (MAC/LLC).
- **Примеры оборудования:** коммутаторы (switch), сетевые карты.
- **Технологии и понятия:** Ethernet, 802.11 (Wi-Fi), MAC/LLC, VLAN, ATN, HDP, Fibre Channel, FrameReplay, HDLC, PPP, Q.921, Token Ring.

## 4. Пример / команда
Работа коммутатора: он получает кадр, смотрит на MAC-адрес назначения и отправляет его в нужный порт. Если MAC неизвестен — рассылает всем (flood).

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| MAC-спуфинг (подмена MAC-адреса) | Port Security на коммутаторах, привязка MAC к порту |
| ARP-спуфинг (перехват трафика внутри LAN) | Dynamic ARP Inspection (DAI), статические ARP-таблицы |
| Атаки на VLAN (VLAN Hopping) | Отключение неиспользуемых портов, настройка native VLAN |
