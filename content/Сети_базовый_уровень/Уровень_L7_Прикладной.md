# Уровень_L7_Прикладной

> [!abstract] Кратко
> Самый верхний уровень [[Модель_OSI]]. Обеспечивает доступ приложений к сетевым услугам (веб-серфинг, почта, передача файлов).

## 1. Зачем нужно
Обеспечивает доступ приложений к сетевым услугам. Реализует протоколы, которые поддерживают конечные пользовательские процессы и сетевые приложения.

## 2. Простыми словами
Это то, что видит пользователь. Браузер, почтовый клиент, мессенджеры. Здесь мы открываем сайты, отправляем письма и качаем файлы.

## 3. Технические детали
- **Функции:** предоставление сетевых услуг пользовательским приложениям.
- **Протоколы и понятия:** DNS, WWW, HTTP, P2P, EMAIL, POP, SMTP, TELNET, SSH, FTP, TFTP.

## 4. Пример / команда
Ввод адреса сайта в браузере (HTTP/HTTPS). Подключение к серверу по SSH для управления Linux.

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| XSS, SQLi, CSRF (атаки на веб-приложения) | WAF (Web Application Firewall), валидация ввода |
| Фишинг (использование SMTP/HTTP для обмана) | Обучение пользователей, почтовые фильтры |
| Атаки на DNS (подмена ответов) | DNSSEC, использование защищённых DNS |
