# ЦОД

> [!abstract] Кратко
> Центр Обработки Данных — сооружение для серверов, сетевого оборудования, хранения. Обеспечивает надёжность (питание, охлаждение), производительность, безопасность. Свой ЦОД оправдан при росте, высокой доступности, требованиях к защите данных.

## 1. Зачем нужно
Понять, куда упирается трехуровневая модель, когда сервис нужен тысячам пользователей из интернета.

## 2. Простыми словами
Завод для серверов: своя электростанция, охлаждение, охрана. Маленькой компании дешевле арендовать, большой — строить.

## 3. Технические детали

**Что обеспечивает:**

- **Надёжность:** резервное питание, охлаждение, защита от пожара/потопа.
- **Производительность:** мощные серверы.
- **Безопасность:** контроль доступа, защита от кибератак.

**Кому нужен:** облачные провайдеры, банки, IT-гиганты, Big Data/ML.

**Когда свой ЦОД оправдан:**

- рост (Big Data, AI — аренда дешевле покупки);
- высокая доступность (магазин с миллионом пользователей);
- безопасность (персональные данные, медицина, карты).

**Маленькой компании** — аренда мощностей или облако дешевле.

## 4. Пример / команда
Проверка инфраструктуры (в облаке):

```bash
# список зон доступности
aws ec2 describe-availability-zones
```

## 5. Для ИБ

| Риск | Защита |
|------|--------|
| Нет резервного питания → простой | Дублирование, UPS, генераторы |
| Нет физической защиты | Контроль доступа, видеонаблюдение |
| Один ЦОД → единая точка отказа | Геораспределение, репликация |
| Нет сегментации внутри ЦОД | Clos, DMZ, VLAN |
